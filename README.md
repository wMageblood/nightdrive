### Nightdrive

The purpose of this app was to learn the basics of MERN stack. \
Vercel Frontend, Render backend. \
Also provide a simple, fast and safe way to apply to a guild in World of Warcraft.

Whenever someone fills up and sends the apply form, an embeded message is sent with the player's apply to a designated channel using discord webhooks.
